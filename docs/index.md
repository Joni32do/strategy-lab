# Strategy Lab

**Play a game. Then find its best strategy.**

Strategy Lab is a collection of games built for exploring strategy: how
likely an outcome is, what the game tree says, where the Nash equilibrium
sits, and how a learning agent discovers a policy by itself. Every game is
a Python class; the browser only draws what the game describes.
